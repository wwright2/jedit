# Building jEdit

A quick guide to building jEdit from this repository. For every Ant target
and how to set up an IDE, see `README.SRC.txt`.

## Requirements

| Tool        | Required version | Tested with                |
|-------------|------------------|----------------------------|
| JDK         | 11 or newer      | 17.0.19 (Azul Zulu)        |
| Apache Ant  | 1.9.10 or newer  | 1.10.17                    |

You don't need to install anything else. On the first build, Ant downloads
Ivy and the other dependencies into `lib/`, so it needs internet access.

## Installing the tools with SDKMAN (no sudo needed)

```bash
# Install SDKMAN if you don't have it: https://sdkman.io/install
source ~/.sdkman/bin/sdkman-init.sh
sdk install java 17.0.19-zulu   # any JDK 11+ works
sdk install ant
```

If `java` or `ant` gives "command not found", SDKMAN isn't loaded in that
shell. Run `source ~/.sdkman/bin/sdkman-init.sh` first, or add that line to
your `~/.bashrc`.

You can also install the tools with your package manager, for example
`sudo apt install openjdk-17-jdk ant`.

## Build

From the repository root:

```bash
ant build      # or just: ant  ("build" is the default target)
```

This:

1. downloads the dependencies into `lib/`
2. compiles the sources into `build/classes/`
3. runs the unit tests (results go in `build/test/`)
4. creates `build/jedit.jar` and copies the modes, macros, keymaps,
   properties and startup scripts into `build/`

A clean build takes about a minute.

## Run

```bash
ant run
# or
java -jar build/jedit.jar
```

jEdit is a Swing desktop app. On WSL2 its window needs WSLg (built into
Windows 11) or an X server.

## Other useful targets

| Target          | What it does                              |
|-----------------|-------------------------------------------|
| `ant test`      | Runs only the unit tests                  |
| `ant run-debug` | Runs jEdit with a debugger port open      |
| `ant clean`     | Deletes the build output                  |
| `ant clean-all` | Also deletes the downloaded `lib/` folder |
| `ant -p`        | Lists every target                        |

## Configuring the build (optional)

To change the `lib/`, `build/` or `dist/` folders, the Ivy version and
similar settings, copy `build.properties.sample` to `build.properties` and
edit it.

## Generated folders

`build/`, `lib/` and `dist/` are generated by the build. Don't commit them.
